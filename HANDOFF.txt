================================================================
2. WHAT THIS PROJECT IS
================================================================

AVG Studio - a Windows desktop app turning a topic into a short-form
(9:16) or long-form (16:9) video. AI writes a brief and script,
generates one image per scene, synthesises narration, plans motion
and captions, renders an mp4.

One process: Python engine + FastAPI on 127.0.0.1 with a per-session
token + React 19 UI in WebView2 via pywebview. Rendering runs in a
spawned child process against a vendored copy of an older engine.

CLAUDE.md is the authority on rules and architecture. Read it fully.
docs/APP_CODING_GUIDE.md is the map of where everything lives.

Interpreter for EVERYTHING is .venv-build/Scripts/python.exe
System `python` lacks the dependencies. `.venv` is also wrong.

    .venv-build/Scripts/python.exe -m pytest tests -q
    .venv-build/Scripts/python.exe -m mypy
    cd web && npm run build && npm run lint
